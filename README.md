# Учебный frontend-проект

## Сайт проекта

https://vikki122222.github.io/kr1-html-css-shop/

## Описание

Проект выполняется в рамках дисциплины «Фронтенд и бэкенд разработка».

Тема проекта: многостраничный сайт интернет-магазина или каталога услуг.

Название проекта: **AEGIS COSPLAY**.

AEGIS COSPLAY — учебный многостраничный сайт интернет-магазина косплей-костюмов.

Основная тематика проекта — косплей, фэнтези и мифология.

## Структура проекта

- `index.html` — главная страница;
- `catalog.html` — каталог товаров;
- `product.html` — подробная страница товара;
- `order.html` — страница оформления заказа;
- `contacts.html` — контактная информация;
- `css/style.css` — файл стилей;
- `js/main.js` — файл JavaScript;
- `images/` — папка для изображений;
- `README.md` — описание проекта;
- `.gitignore` — список файлов, исключённых из Git;
- `sitemap.xml` — простая карта сайта;
- Open Graph-теги — базовая разметка для отображения ссылок.

## Обязательные страницы

## Главная страница

На главной странице реализованы:

- главный экран;
- преимущества магазина;
- популярные товары;
- карточки товаров;
- изображения костюмов;
- цены;
- кнопки заказа;
- якорные ссылки;
- модальное окно с формой заказа.

## Якорные ссылки

На главной странице используются якорные ссылки:

- `#advantages` — переход к блоку преимуществ;
- `#popular` — переход к популярным товарам.

На других страницах используются ссылки:

- `index.html#advantages`;
- `index.html#popular`.

Они возвращают пользователя на главную страницу и прокручивают её к нужному блоку.

## Каталог

На странице `catalog.html` реализованы:

- хлебные крошки;
- статические фильтры;
- категории товаров;
- карточки товаров;
- названия;
- краткие описания;
- цены;
- кнопки «Подробнее»;
- фотографии части товаров;
- заглушки для товаров без изображений.

Фильтры являются статическими и используются как часть интерфейса.

## Страница товара

В файле `product.html` находится подробная страница костюма Афины.

На странице реализованы:

- изображение товара;
- название;
- категория;
- описание;
- цена;
- таблица характеристик;
- комплектация;
- дополнительная информация;
- кнопка перехода к оформлению заказа.

## Таблица характеристик

На странице товара используется HTML-таблица.

В ней применяются:

- `table`;
- `caption`;
- `thead`;
- `tbody`;
- `tr`;
- `th`;
- `td`.

В таблице указаны:

- стиль;
- размеры;
- цвет;
- материал;
- назначение.

## Страница оформления заказа

В файле `order.html` находится форма оформления заказа.

Форма содержит:

- имя;
- e-mail;
- телефон;
- размер костюма;
- желаемую дату;
- комментарий;
- согласие на обработку персональных данных;
- кнопку оформления заказа.

После успешной проверки формы появляется сообщение:

«Заказ успешно оформлен! Мы свяжемся с вами для подтверждения.»

## Модальное окно

На главной странице используется модальное окно `dialog`.

При нажатии на кнопку «Заказать»:

- открывается форма;
- определяется выбранный товар;
- название товара записывается в скрытое поле;
- выполняется проверка формы;
- показывается сообщение об успешном заказе;
- форма очищается;
- окно можно закрыть кнопкой «Закрыть».

## Использование Flexbox и Grid

В проекте используются:

- Flexbox для основного меню;
- Flexbox для внутренней структуры карточек товаров;
- Flexbox для кнопок;
- Flexbox для элементов формы;
- CSS Grid для сетки карточек;
- CSS Grid для страницы каталога с фильтрами и списком товаров;
- CSS Grid для страницы товара;
- CSS Grid для страницы оформления заказа.

## БЭМ-структура проекта

В проекте используются следующие БЭМ-блоки:

- `site-header` — шапка сайта;
- `site-nav` — основная навигация;
- `breadcrumbs` — хлебные крошки;
- `hero` — первый экран главной страницы;
- `products-grid` — сетка товаров;
- `product-card` — карточка товара;
- `catalog-layout` — структура страницы каталога;
- `catalog-filters` — фильтры каталога;
- `product` — страница товара;
- `product-table` — таблица характеристик;
- `order-dialog` — модальное окно заявки;
- `order-form` — форма заявки;
- `order-page` — страница оформления заказа;
- `order-summary` — информация о выбранном товаре;
- `button` — кнопка;
- `site-footer` — подвал сайта.

Пример элемента:

`product-card__title`

Пример модификатора:

`product-card--featured`

## Позиционирование

В проекте используются:

- `position: sticky` — для шапки сайта;
- `position: relative` — для карточки товара;
- `position: absolute` — для бейджа «ХИТ»;
- `z-index` — для управления слоями элементов.

## Адаптивность

В проекте используются медиазапросы.

На небольших экранах:

- сетка товаров перестраивается;
- каталог становится одноколоночным;
- страница товара становится одноколоночной;
- страница заказа перестраивается;
- кнопки формы располагаются вертикально.
